# HomePDF product context

## Register

product

## Users and purpose

Windows users read, search, edit and convert PDFs locally. The portable desktop application provides PDF reading and toolkit workflows without requiring a Python installation.

## Identity requirement

The user requested the exact SnagItOpen icon family, with a white H replacing S and deep green replacing red. Familiar Windows integration and recognition at small sizes guide this change. Preserve the reference silhouette, glyph weight, gradient, border and shadow. Scope is the app identity and shortcuts; existing reader layouts remain as established.

## Accessibility

Keep high glyph/background contrast and supply native icon frames at common Windows display scales.
